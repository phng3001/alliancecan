> **Notes:**
- The output `.vcf` file generated by snippy lack annotation for SNPs in non-coding regions (e.g. rRNAs, tRNAs)
- So the `.filt.vcf` file is used to add SnpEff annotation
- Chromosome's names in snippy's vcf files usually needs to be fixed to be compatible with reference fasta and gff files, or vice versa. E.g.
    * AE007317 in snippy's vcf but AE007317.1 in reference fasta and gff files
    * NMDC60018531_1 in snippy's vcf but gnl|Prokka|NMDC60018531_1 in reference fasta and gff files
